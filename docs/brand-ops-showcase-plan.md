# 브랜드 운영 현황 공개 — 기획 (ISS-481)

대표님 지시 2026-11-20: "imPD 회원의 브랜드가 어떻게 운영되고 있는지 적극적으로 보여야 한다. 회원·활성화가 얼마나 늘고 있는지(시계열 그래프), 얼마나 많은 소통이 이루어지는지를 허용 범위 안에서 미가입자에게 자극이 되도록. 1차는 데이터가 가장 많은 myaji35 회원(/kang-seung-sig)으로."

## 1. 누구에게 무엇을

| 미가입 방문자(1인 사업자·크리에이터) | imPD 전체가 커지고 있다(회원·활성 회원 추이), 회원 브랜드가 실제로 소통하고 있다(주간 방문·문의·후기·게시) | "나도 만들기" 가입 |

| 공개 회원 페이지 방문자 | 이 브랜드가 꾸준히 활동한다는 신뢰 신호 | 문의 |

## 2. 화면
1. **`/growth` 공개 페이지 "imPD는 지금"** (홈·둘러보기에서 연결)
   - 주간 시계열: 누적 회원 / 활성 회원(최근 30일 안에 페이지 갱신·게시·로그인·문의 응대 중 하나) — 12주·26주 전환
   - 주간 소통량(합계, 익명): 회원 페이지 방문, 문의 접수, 후기 등록, 게시물 발행, SNS 발행
   - "이번 주" 핵심 숫자 3개 + 전주 대비 변화
   - 운영 중인 브랜드 카드(노출 동의한 회원만) — 1차: kang-seung-sig
   - 주요 버튼 1개: "내 페이지 만들기"
2. **회원 공개 페이지 `/:slug/brand` "이 브랜드는 이렇게 운영돼요"** (SocialDoctors 노출 동의 회원만)
   - 12주 활동 그래프(방문·문의 건수·게시·SNS 발행), 연결 매체(SocialDoctors·Townin), 최근 게시물
   - 문의 내용·연락처·방문자 정보는 절대 노출하지 않음 — 건수만
3. **회원 관리 "내 브랜드" (`/:slug/admin/brand`)** — 같은 그래프 + 공개 여부 표시(무엇이 바깥에 보이는지)

## 3. 허용 범위 (개인정보·신뢰)
- 공개는 **합계·건수만**. 개별 문의·후기 원문·방문자 IP/도시·이메일은 공개하지 않는다.
- 회원 개별 수치는 `pro_consents.socialdoctors_exposure` 동의 회원만, 철회 즉시 비공개.
- 작은 숫자 보호: 주간 값 1~2건은 "3건 미만"으로 묶어 표시(재식별 방지), 0은 0.
- 로봇·내부(운영자·본인) 방문 제외, 각 그래프에 "기준·집계 시점" 표기.
- 숫자를 꾸미지 않는다: 예시·가짜 데이터는 개발 환경에서만, 화면에 "예시" 표시.

## 4. 데이터 정의

| 활성 회원 | 그 주 기준 30일 안에 (member_posts 발행 / 페이지 수정 updated_at / last_sign_in_at / member_inquiries 읽음 / sns 발행) 중 1개 이상 |
| 방문 | analytics_events page_view, page_path = /:slug…, 로봇 UA·운영자·본인 세션 제외 |

| 후기 | member_reviews 승인분 |
| 게시 | member_posts is_published, published_at |
| SNS 발행 | sns_post_histories status=success |

## 5. 1차 데이터 (kang-seung-sig)
- 운영 DB에만 실데이터가 있다(로컬 DB는 시험 회원 2명). 운영 공개 페이지 확인값: 활동 6개월째, 이번 주 방문 9회.
- 읽기 전용 내보내기 작업 `bin/rails impd:export_activity[kang-seung-sig]`(개인정보 없는 주간 합계 JSON)을 만들고, 로컬에는 `impd:import_activity`로 넣어 같은 모양으로 반복 평가한다. 운영 실행은 대표님 확인 후.
- 그 전까지 로컬은 실제 공개값(6개월·주 9회 방문)에 맞춘 개발용 예시 데이터로 작업하고 화면에 "예시 데이터"를 표시한다.
