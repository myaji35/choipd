## ISS-530 바닥글 (ISS-520 반응형 변경) — 54/70 통과
- 정렬: 1280 3열(브랜드 2fr·서비스·연락처), 390 브랜드 전폭 + 2열. 열 시작선 일치, 링크 간격 10px 일정.
- 위계: B2B/B2G 문의하기만 강조색(#ff7850) — 바닥글 주요 행동이 한눈에 보임.
- 결함(분리): 소개 문장이 `max-width:280px` 에서 "통합 브랜드 허 / 브."로 낱글자가 다음 줄로 떨어짐(1280·390 모두) → 새 카드(한국어 단어 단위 줄바꿈).
- 결함(기존 카드): 저작권 줄·하단 링크·소제목 대비 1.8~2.6:1 → ISS-532.

## ISS-538 교육 분류 버튼 (ISS-531) — 58/70 통과
- 390: 4개 한 줄, 320: 3+1 두 줄, 글자 쪼개짐 0, 높이 37.5px.
- 선택 상태: 채움 배경 + 그림자 + 진한 글자로 비선택(테두리만)과 형태가 다름, 27e0f98 부터 aria-current 로도 알림.
- 분류별 선택색(주황·연두·노랑·파랑)이 일관되게 같은 형태로 적용됨.
- 관찰(분리): 320px 소개 문구 "강좌 / 로" 낱글자 줄바꿈 → 위와 같은 새 카드. 빈 목록 안내 글자(rgba .3) 대비 부족 → 새 카드.
- 참고: 전체 캡처에서 B2B 구역이 비어 보이는 것은 스크롤 시 나타나는 `.reveal` 이 캡처에서 그려지지 않은 것(turbo_reveal_check 로 스크롤 표시 확인됨), 결함 아님.
