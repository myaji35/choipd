# 네이버 인물정보 관리 기능 기획 (2026-11-19)

대표님 지시: "네이버 인물정보도 같은 방식으로 기획해서 진행해" (LinkedIn 기획 `docs/linkedin-management-plan.md`와 같은 방식).

## 방식
- 대표님 Mac 의 ego 브라우저(네이버 로그인 myaji)로 본인참여 사이트 내부 API를 읽어 원문 그대로 사본으로 저장하고, 앱(`/pd/people_accounts`)에서 항목별로 정리해 보여준다.
  - `GET api.myprofile.naver.com/api/auth-list?size=10000&page=0` — 권한 목록(peopleId, dss, 권한 상태, 위임 종료일)
  - `GET .../api/people-select?peopleId=<id>` — 인물정보 전체(약 155개 필드 + 경력·소속·학력·수상·자격증·사이트·작품 등 배열)
  - `GET .../api/result-list?status=ING|END&page=0` — 신청 진행/완료 내역
- **통합검색 노출 번호는 `dss`(42140857)이고, 본인참여 번호는 `peopleId`(2840091)다.** 검색 링크는 `os=<dss>`로 만든다(2026-11-19 실측).
- 읽기는 자동으로 한다. **수정 신청 제출은 앱에서 대표님이 "승인"을 누른 건만 실행**한다. 네이버 심사를 거치는 외부 행위이기 때문이다. 삭제 신청과 동의 철회는 되돌릴 수 없어 만들지 않는다.

- 경력 3, 소속 2(주식회사 가가호호 대표이사 등), 학력 1(가천대학교 전자계산과), 작품 1(도서 「이만큼 할 수 있다」)
- **비어 있음**: 사이트 정보(블로그·인스타·유튜브·LinkedIn), 수상, 자격증, 별명, 취미
- 진행 중인 신청 0건, 완료 0건
