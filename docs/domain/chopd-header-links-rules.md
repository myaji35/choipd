# chopd 헤더 링크 규칙 (ISS-573, ISS-557 후속)

대상: `app/views/layouts/_chopd_header.html.erb` (데스크톱 메뉴 · 모바일 메뉴 `#mobile-nav` · 회원 세션 영역 · '강좌 문의' 버튼)

ISS-557 은 '소개'가 없는 `#identity` 를 가리키던 죽은 링크 수정이다(ff54c2c). 돈·회원 저장 규칙은 바뀌지 않았고, 방문자·회원이 헤더에서 겪는 이동 규칙만 정리한다.

## 규칙
| ID | 역할 | 규칙 | 자동 점검 |
|---|---|---|---|
| R1 | 방문자 | '소개'는 데스크톱·모바일 메뉴 모두 발행인 인사말 화면(`/media/greeting`)으로 간다 | `bin/rails test test/integration/chopd_header_links_test.rb` |
| R2 | 방문자 | 헤더·모바일 메뉴의 링크는 `#…` 같은 빈 대상이 없고, 내부 링크는 모두 200 또는 3xx 로 열린다 | 같은 테스트(전체 내부 링크 GET) |
| R3 | 모바일 방문자 | 모바일 메뉴에서 링크를 누르면 이동하면서 메뉴가 닫히고 버튼의 aria-expanded 가 false 로 돌아간다 | `node script/qa/chopd_mobile_menu_check.cjs` (introNav finalPath /media/greeting, menuDisplay none) |
| R4 | 방문자 | 로그인 전에는 '회원가입'·'로그인'이, 로그인 뒤에는 이름·'내 페이지'(`/<회원 주소>`)·'로그아웃'(확인 창)이 보인다 — 데스크톱·모바일 동일 | 로그인 전: R2 테스트. **로그인 뒤: 자동 점검 없음 → 갭 G1** |
| R5 | 모든 방문자 | '강좌 문의' 버튼은 모든 chopd 화면 헤더(데스크톱)와 모바일 메뉴에 있고 `/inquiries/new` 로 간다 | R2 테스트(내부 링크 200) |
| R6 | 모든 방문자 | 헤더 글자는 배경 대비 4.5:1 이상이다 | 메뉴 글자 rgba(255,255,255,.55)~.7 통과. **'강좌 문의' 버튼 흰 글자/#ff4d1c 3.32:1 미달 → 갭 G2** |

## 시나리오
- S1 모바일 방문자: 390px `/education` → 햄버거 → '소개' → `/media/greeting`, 메뉴 닫힘, 콘솔 오류 0 (2026-11-25 실측 통과)
- S2 로그인한 회원: chopd 화면 헤더 '내 페이지' → 자기 공개 페이지, '로그아웃' → 확인 창 뒤 로그아웃 (자동 점검 없음)
- S3 방문자: 1280px 어느 chopd 화면에서든 '강좌 문의' → 문의 양식

## 찾은 갭
- G1 (R4): 로그인한 회원의 chopd 헤더(내 페이지 링크 주소, 로그아웃 양식, 회원가입·로그인 숨김)를 확인하는 테스트가 없다. `public_pages_test` 는 홈(impd 레이아웃) 히어로 버튼만 본다 → 커버리지 카드.
- G2 (R6): '강좌 문의' 버튼 흰 글자가 #ff4d1c 위 3.32:1(13px 굵게, 일반 글자 기준 4.5 미달). 문의 양식 제출 버튼은 이미 어두운 글자(#0a0e1a, 5.8:1)로 맞춰져 있다 → 디자인 수정 카드.
- 관찰(카드 없음): '소개'가 가는 곳이 한국환경저널 발행인 인사말이다. 최범희 PD 개인 소개 전용 화면은 없다. 별도 소개 화면을 만들지는 콘텐츠 방향 문제라 이번에는 기록만 남긴다. 인사말 화면 글자 가독성은 ISS-571 에서 다룬다.
