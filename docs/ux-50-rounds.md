# imPD 전체 화면 개선 50회차 (2026-11-19 시작)

대표님 지시: "impd 전체 화면 디자인을 개인사업자, 1인 크리에이터 등이 충분히 호감을 가질 만한 내용으로 디자인, ui/ux 개선을 100%에 도전하자. 50회 개선안을 찾으면서 회차별로 진행하자." / "화면디자인, ui/ux 개선은 ego를 이용해서 해."

## 진행 방식
- 회차마다 ego로 개선 전 캡처(데스크톱 1440·휴대폰 390, `mobile:true` 지정) → Codex 구현 → ego로 개선 후 캡처·비교 → 테스트 → 커밋.
- 한 회차 = 한 가지 눈에 보이는 개선(또는 같은 화면의 밀접한 묶음).
- 회차를 진행하며 새 개선안을 찾으면 목록 뒤에 추가하고, 끝난 회차에는 ✅와 커밋을 적는다.

## 대상과 톤
- 대상: 개인사업자(가게·공방·서비스업), 1인 크리에이터, 보험설계사 같은 영업 전문직, 강사.
- 호감 요소: "나도 금방 이렇게 될 수 있겠다"(쉬움) · "믿을 만하다"(실제 근거) · "내 얘기다"(내 직업이 보임) · "부담 없다"(무료로 시작, 가격이 또렷함).
- 지킬 것: 실제 근거 없는 후기·숫자는 쓰지 않는다(예시는 "예시"로 표시). 개발자 용어(MD·TXT·§ 등)를 쓰지 않는다. 색에만 의존하지 않는다.
